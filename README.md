# Portfolio Web - Santiago Ledesma

## Descripción
Portfolio personal desarrollado como actividad integradora de la Unidad 3 de Programación Web.

## Tecnologías utilizadas
- HTML5 (etiquetas semánticas)
- CSS3 (Flexbox, Grid, variables, media queries, animaciones)
- JavaScript
- Git y GitHub

## Funcionalidades
- Modo claro/oscuro con interruptor animado
- Foto de perfil con efecto flip que lleva a mi GitHub
- Galería de proyectos en cuadrícula, adaptable a distintos tamaños de pantalla
- Formulario de contacto con validación y contador de caracteres

## Cómo visualizarlo
Descargar o clonar el repositorio y abrir `index.html` en el navegador.
